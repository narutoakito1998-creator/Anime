# uwurposting

Добро пожаловать в uwurposting! Это аниме-приложение, где вы можете смотреть аниме, читать мангу и общаться с другими пользователями и даже с аниме-ИИ.

## Особенности

*   Просмотр аниме и чтение манги
*   Общение с другими пользователями в режиме реального времени
*   Чат с аниме-ИИ
*   И многое другое!

## Технологический стек

*   **Фронтенд:** React
*   **Бэкенд:** Python (Flask)
